# PocketSmart AI

### Your Smart Budget & Recommendation Assistant

PocketSmart AI is a Generative AI-powered recommendation system that helps users make smart and budget-friendly decisions for different needs.

## 📌 Project Overview

Managing a budget while planning a home interior, party, or jewelry purchase can be difficult. PocketSmart AI provides personalized recommendations based on the user's budget, preferences, and requirements.

## ✨ Key Features

- 🏠 Home Interior Planner
- 🎉 Party Planner
- 💎 Jewelry Planner
- 💰 Budget-based recommendations
- 🤖 AI-powered personalized suggestions
- 👤 User Registration and Login
- 💾 Save recommended plans
- 📜 View recommendation history
- 🖼️ Optional image input for Jewelry Planner
- 🔐 Protected user pages

## 🏠 Home Planner

Users can enter their budget, room type, preferred style, and required items. The system generates suitable recommendations based on their requirements and budget.

## 🎉 Party Planner

Users can provide their budget, number of guests, event type, and requirements. The system generates recommendations for party-related needs such as food, venue, decoration, and entertainment.

## 💎 Jewelry Planner

Users can enter their budget, occasion, and preferred style. They can also optionally provide an outfit image to receive suitable jewelry recommendations.

## ⚙️ How It Works

1. User enters their requirements.
2. PocketSmart AI processes the budget and preferences.
3. AI generates personalized recommendations.
4. The recommendations are displayed to the user.
5. Users can save their plans and view them later in History.
